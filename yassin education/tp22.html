Publier et voir sa première page HTML sur Git et GitHub

Ce document détaille la démarche à suivre pour héberger et partager gratuitement votre première page Web en ligne en utilisant Git et la fonctionnalité GitHub Pages.

Étape 1 : Préparer votre fichier HTML

Assurez-vous que votre page principale s'appelle impérativement index.html (en minuscules). C'est le fichier par défaut que GitHub recherche pour afficher votre site.

Étape 2 : Créer un dépôt (Repository) sur GitHub

  1. Connectez-vous à votre compte GitHub.
  2. En haut à droite, cliquez sur le bouton + puis sur New repository.
  3. Donnez un nom à votre dépôt (par exemple : mon-premier-site).
  4. Sélectionnez le mode Public (nécessaire pour que GitHub Pages soit gratuit et accessible publiquement).
  5. Ne cochez aucune case supplémentaire (pas de README, pas de fichier de configuration, pas de licence).
  6. Cliquez sur Create repository.

Étape 3 : Envoyer votre code depuis votre ordinateur

Ouvrez votre terminal (ou Git Bash) à l'intérieur du dossier contenant votre fichier index.html, puis exécutez les commandes suivantes une par une :

1. Initialiser Git :

git init

2. Renommer la branche principale en main :

git branch -M main

3. Lier votre projet local au dépôt distant GitHub (remplacez l'URL par la vôtre) :

git remote add origin https://github.com/votre-nom-utilisateur/mon-premier-site.git

4. Ajouter et valider (commit) votre fichier :

git add index.html
git commit -m "Premier commit : ajout de la page index.html"

5. Envoyer le code sur GitHub (push) :

git push -u origin main

Étape 4 : Activer GitHub Pages

  1. Rendez-vous sur la page de votre dépôt sur le site de GitHub.
  2. Cliquez sur l'onglet Settings (Paramètres) tout en haut.
  3. Dans le menu de gauche, repérez la section Code and automation et cliquez sur Pages.
  4. Sous la section Build and deployment :
    • Sous Source, choisissez Deploy from a branch.
    • Sous Branch, sélectionnez la branche main et le dossier / (root).
    • Cliquez sur Save.

Étape 5 : Accéder à votre site en ligne

Patientez une petite minute, puis actualisez la page des paramètres Pages.

Un lien URL apparaîtra en haut (de type https://votre-nom-utilisateur.github.io/mon-premier-site/). Cliquez dessus pour visualiser votre site Web en direct sur Internet !
